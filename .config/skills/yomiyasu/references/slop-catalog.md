# AI生成文の不自然な語彙・構文カタログ

本カタログは、日本語LLM特有の不自然な語彙・構文パターンをまとめた辞書です。

---

## 1. AI偏愛動詞・比喩動詞

抽象的な事象や技術操作を、安易な比喩動詞で言い換える傾向を解体します。

| AI偏愛動詞 | AI特有の用例 | 自然な人間表現への修正方針 |
|---|---|---|
| **効く / 効いてくる** | 「地味に効きます」「〜が効いてくる」 | 「〜の役に立つ」「効果がある」「〜を防げる」 |
| **壊れる** | 「静かに壊れる」「もう片方が壊れる」 | 「要件を満たせなくなる」「例外が出る」「整合性が崩れる」 |
| **倒す** | 「〜側に倒す」「残さない側に倒す」 | 「〜を原則とする」「除外する」「〜を採択する」 |
| **溶かす** | 「時間を溶かしました」 | 「多くの時間を費やした」「調査に時間がかかった」 |
| **潰す** | 「1つずつ潰していく」 | 「エラーを1件ずつ解消する」「原因を1つずつ検証する」 |
| **踏み込む** | 「〜まで踏み込んで」 | 「〜の詳細まで掘り下げて」「〜の内部実装まで調べて」 |
| **引き返す** | 「動かしながら引き返す」 | 「元の状態に戻す」「ロールバックする」 |
| **添える** | 「経路が代わりに添える」 | 「参照する」「付与する」「渡す」 |
| **収斂する** | 「その価格帯に収斂した」 | 「〜に決まった」「〜に落ち着いた」 |
| **沈黙する** | 「静かに沈黙する」 | 「エラーを出さずに終了する」「応答しない」 |
| **黙って** | 「黙って無視される」「黙って捨てられる」 | 「通知なく破棄される」「ログを出さずにスキップする」 |

## 2. 英語直訳調・統語リーク

英語表現を直訳した結果生じる不自然な構文を平文化します。

| 英語の原表現 | AIの直訳日本語 | 自然な日本語 |
|---|---|---|
| *silently fail / ignored* | 「静かに壊れる」「黙って無視される」 | 「エラーを出さずに失敗する」「警告なしで無視される」 |
| *the moment ...* | 「〜した瞬間」「〜した瞬間に」 | 「〜するとすぐに」「〜した直後に」「〜した時点で」 |
| *single source of truth* | 「〜を正本にする」「〜の正本として」 | 「信頼できる唯一の情報源とする」「マスターデータとする」 |
| *point to / suggest* | 「〜を指している」「〜を示唆している」 | 「〜を表している」「〜と考えられる」「〜を意味する」 |
| *load-bearing* | 「耐力のある」「構造を支える」 | 「不可欠な」「根幹となる」「外せない」 |
| *it is not X, it is Y* | 「Xではなく、Yです」 | 「Yです」（不要なXの否定を削る） |
| *delve into* | 「〜に深く分け入る」「深掘りする」 | 「詳しく調べる」「具体的に見ていく」 |
| *em dash (— / ―)* | 「〜――とりわけ〜――は」 | 「〜をはじめとする〜は」（助詞で接続） |

## 3. 2026年急増語（Qiita 7万件調査に基づく分類）

AI普及以後の技術文書で急増した比喩・評価名詞を解体する。

| 分類 | 急増した語彙 | AI用例 | 修正方針 |
|---|---|---|---|
| **障害・失敗の比喩** | `事故` `混ざる` `落とし穴` `破綻` `実害` `素通り` | 「〜という事故」「落とし穴があります」 | 「不整合」「例外発生」「考慮すべき点」 |
| **確認・検証の比喩** | `実測` `疑う` `照合` `突き合わせる` `断定` `取り違える` | 「実測では」「〜を取り違えると」 | 「計測値」「確認する」「比較検証する」 |
| **役割・位置の比喩** | `入口` `土台` `道具` `核心` `主役` `構図` `線引き` | 「〜の入口として」「〜するための土台」 | 「導入」「前提条件」「基礎知識」 |
| **評価・結論の定型** | `既定` `別物` `定番` `要点` `定石` `桁違い` | 「既定では」「〜とは別物です」 | 「初期設定では」「性質が異なります」 |

## 4. 必殺技造語・体験の壮大化

個人のささやかな体験や日常的な技術判断を、重厚な熟語で大げさに語る傾向を排除します。

| 壮大化熟語群 | AIの典型的な不自然な記述 | 自然な表現 |
|---|---|---|
| `真理` `真実` `結末` `宿命` `運命` `境地` `極致` `究極` `虚飾` `虚像` `美学` `深淵` `禁欲的` `優美` `冷徹` `残酷` `凝縮` `結晶` | スペックという虚飾を剥ぎ取った時、指先が感知した真実とは。 | 3年使いましたが、REALFORCEは打鍵感が柔らかすぎると感じ、私はHHKBのほうが好みでした。 |

個人の日常や業務エピソードに、普遍の教訓を不自然に付加しない方針をとる。

## 5. 質感を装う疑似具体語・ビジネスジャーゴン

一見プロっぽく見えるが、中身が何もない空虚なキーワードを排除します。

| 分類 | 対象語彙 | 是正ルール |
|---|---|---|
| **質感を装う語** | `手触り` `肌感` `肌感覚` `体温` `温度感` `熱量` `血の通った` `泥臭い` | 実際に操作した手順、ログ、実測値を具体的に書く。 |
| **認知を装う語** | `解像度`（解像度を上げる/高い） `腹落ち` `メンタルモデル` `文脈` | 何をどこまで調査・検討したのかを具体的に書く。 |
| **評価を装う語** | `本質` `本質的` `地に足のついた` `等身大` | 空疎な修飾を削り、客観的な事実のみを書く。 |
| **未定義造語** | `意思決定OS` などの勝手な比喩命名 | 標準的な技術用語または機能説明で書く。 |

## 6. メタ宣言・時間稼ぎフィラー

読者の感情や理解度を先回りしてコントロールしようとする無駄な前置きや後置句を削除します。

| 分類 | 対象表現 | 是正ルール |
|---|---|---|
| **前置フィラー** | `重要なのは` `結論から言うと` `正直に言うと` `避けたいのは` `ここで注目すべきは` | 前置きを丸ごと削除し、要点の主文から書き始める。 |
| **後置ラベリング** | `〜というわけです` `〜に他なりません` `〜と言えるでしょう` `面白いのはここです` | 文末を断定（〜である、〜です）または事実記述で閉じる。 |
| **定型クロージング** | `いかがでしたでしょうか` `ぜひ試してみてください` `〜の参考になれば幸いです` | 形式的呼びかけを削り、本文の自然な結びで終わる。 |
