# 配布文書の自立可読性を保つための日本語ライティング規範

配布される文書は、書き手の口頭説明が付かない状態で読まれる。読み手は後から文章だけを読み、そこから「誰が・何を・どうするか」を復元する。
この規範は、書き手が頭の中に持っている文脈を文に書き出し、読み手に補完を求めない文書を作るためのものである。「このくらい言わなくても分かる」が通じているなら、問題は起きていない。指摘が来た時点で、通じていなかったと判断する。

簡潔さは語数を減らすことであって、文の成分(主語・動詞・目的語)を削ることではない。短文・対句・体言止め・名詞化は、書き手には要約に見えるが、読み手には省かれた成分を復元する作業を強いる。

## 対象と対象外

この規範は、読み手が通読せずに必要な箇所を探して読む文書を対象にする。

- **対象**は走査される文書である。報告、依頼書、引き継ぎ資料、議事メモ、Issue と PR の本文、設計メモ、チャットの回答で後から参照されるものが入る。
- **対象外**は読み物として通読させる文章(記事、ブログ、docs/explanation)である。これらは `../cognitive-rhythm-writing/SKILL.md`(緩急の設計)と `../japanese-tech-writing/SKILL.md`(記事の表記)に従う。本規範の「主文を先に」「体言止めをしない」は、読み物では意図的に破ってよい。

## 併用する規範と役割分担

文体を扱う規範は 4 つあり、扱う階層が違う。次の表は、それぞれが何を扱い、本規範とどう組み合わせるかを示す。

| 規範 | 扱う階層 | 本規範との関係 |
|---|---|---|
| 本規範 | 文書と節。主文の位置、登場人物の明示、文脈の自立、依頼書の骨格 | 文書を書く前に読む |
| `../yomiyasu/SKILL.md` | 文。主述関係の復元、比喩動詞の具体化、前置きフィラーの除去、読点と装飾の抑制 | 本規範で骨格を作った後、文単位の推敲と機械検査に使う。読む指摘と読まない指摘は後述の表に従う |
| `../japanese-tech-writing/SKILL.md` | 記事の表記と実録の検証 | 対象が記事のときだけ。本規範とは同時に使わない |
| `../cognitive-rhythm-writing/SKILL.md` | 読み物の緩急 | 対象が読み物のときだけ。本規範とは同時に使わない |

同じターンで読み込む規範は、本規範と yomiyasu までにする。yomiyasu の README が警告しているとおり、文体を扱う規範を 3 つ以上同時に有効にすると指示が干渉する。

## 規範

### 1. 主文を先に、完全な文で書く

- 文書・節・段落の冒頭に「誰が何をする」か「結論は何か」を書く。その文には主語と動詞を付ける。見出し・表・箇条書きはその文の後に置く。
- 見出しの直下に表を置かない。表の前に、その表が何を並べていて読み手が何を読み取ればよいかを 1 文で書く。箇条書きで始めてよいのは、見出しがその節の主文を兼ねている場合(規範やチェックリストの列挙)だけ。
- 一言で答えられる質問には、構造を作らず 1 文で答える。

### 2. 文の成分を削らない

- 体言止め、対句、標語で要点を言い切らない。並べて言いたくなったら、一文ずつ主語と動詞を付ける。
- 名詞化で動作を隠さない。「候補選択の再現率の測定」ではなく「候補選択の再現率を測る」と書く。
- 表のセルも名詞の羅列にしない。短い文か、少なくとも動詞を含む句にする。見出し行だけは名詞でよい。
- 読点は文法上の切れ目にだけ置く。息継ぎのための読点を入れない。短文を読点でつなぎ合わせて 1 文にしない。1 文の読点は 2 つまでを目安にする。

### 3. 登場人物を役割名で明示する

- 「こっち」「先方」「あの人」「うち」で済ませず、役割名(依頼者、実施者、レビュアー、弁護士など)で書く。
- 登場人物が 3 人以上いる文書では、冒頭に役割表(役割、誰か、何を決めるか)を置く。
- 固有名詞、略語、チケット ID、ファイル名は、初出で何かを書く。2 回目以降は短く呼んでよい。
- 各段落に「誰が・何を・どうした」の 3 要素が揃っているかを確認する。主語が省かれていてよいのは、直前の文と同じ主語が続く場合だけ。

### 4. 直前の会話に依存しない

- 直前の会話、口頭説明、前回の資料を読み手が知っている前提で書かない。「前に話したやつ」ではなく、対象を名指しする。
- 参照は場所つきで書く。ファイルならパスを、チケットなら ID を、文書なら節番号を添える。「後述」「前述」にも節番号を添える。
- 書き手自身の記憶を頼りに「分かるだろう」と判断しない。判断するのは読み手であり、読み手は書き手の記憶を持っていない。

### 5. 依頼書・引き継ぎ文書の骨格

依頼書と引き継ぎ文書は、次の順で節を立てる。節の名前は変えてよいが、順序と「依頼者がやること」を省かない。依頼者自身が何をすべきかを文書に書かないと、依頼者が混乱する。

1. 目的。この文書(この測定、この作業)で何を決めるか。
2. 現状。読み手が知らない前提の事実を書く。
3. 役割別の「〜がやること」。実施者、依頼者、第三者(レビュアー、注釈者など)の順に、別々の節で書く。
4. 成果物と置き場。ファイル名とパスを書く。
5. 完了条件。
6. やらないこと。実施者が善意でやりがちで、依頼者の設計と衝突すること。
7. 背景資料。場所つき。

## 違反例と修正例

| 違反 | 何が省かれているか | 修正 |

## yomiyasu の指摘の読み方

yomiyasu の lint(`../yomiyasu/scripts/yomiyasu_lint.py`)は文単位の機械検査として使う。ただし本環境の表記と衝突する指摘があるので、次の表に従って読む。上流のファイルは書き換えない(`../yomiyasu/UPSTREAM.md`)。次の表は、指摘の種類ごとに従うか読まないかを示す。

| yomiyasu の指摘 | 扱い | 理由 |
|---|---|---|
| 比喩動詞(効く、壊れる、倒す、溶かす、潰す)、非生物主語 | 従う | 読み手に比喩の解釈を求める。本規範の 2 と同じ趣旨 |
| 前置きフィラー(重要なのは、結論から言うと)、定型クロージング | 従う | 主文の前に置かれる前置きは、主文を遅らせる |
| 否定対比(A ではなく B) | 従う。ただし対比が内容そのもののとき(設計案の比較)は残す | 修辞としての否定対比と、比較としての否定対比は別 |
| 読点 3 つ以上の文、同一文末の 3 連続 | 従う | 本規範の 2 と同じ |
| 絵文字、文末コロン、ダッシュ記号 | 従う | 配布文書に装飾は要らない |
| 英単語前後の半角空白 | **読まない** | 本環境の表記は和欧文間に半角スペースを置く(`../japanese-tech-writing/SKILL.md` と全スキルの文体がこの表記) |
| 太字頻度、箇条書き比率 | **走査型文書では読まない** | 走査される文書では見出し・表・箇条書きが区分の分解を肩代わりする(グローバル CLAUDE.md「報告と分解の形」)。読み物に適用するときだけ従う |
| スロップ語「正本」 | **読まない** | 本環境では「正本」は版管理と法律文書の用語として使う |
| スロップ語「土台」「本質的」「装置」など | 文脈で判断する | 専門用語や固有の名称(例: cognitive-rhythm-writing の「装置」)は言い換えない。yomiyasu 自身も専門用語の保持を指示している |

## 執筆後の点検手順

書き終えたら、次の 4 つを順に行う。

1. **文脈除去テスト**。直前の会話と自分の記憶を使わずに文書だけを読み直し、各節で「誰が・何を・どうする」を言えるかを確認する。言えない節は主文を足す。
2. **役割テスト**。登場人物が役割表にあるか、「こっち」「先方」「あの人」「例の」「さっき」が残っていないかを確認する。
3. **同梱スクリプト**を走らせる。節の冒頭の主文の欠落・本文と箇条書きの体言止め・文脈依存語・読点の多い文・対句の疑いを列挙する。

   ```bash
   python3 <スキル配置ディレクトリ>/scripts/standalone_check.py <対象ファイル>
   ```

   `--with-yomiyasu` を付けると、隣の `yomiyasu/scripts/yomiyasu_lint.py` を続けて実行し、上の表で「読まない」とした指摘を除いて表示する。判定は物理行ではなく段落単位で行うので、Markdown の折り返し(読点の後で改行した 1 文)は体言止めに数えない。終了コードは、本スクリプトの WARN か yomiyasu の warn があれば 1、ファイルを読めないか lint を実行できなければ 2、それ以外は 0 になる。INFO と yomiyasu の info は表示だけで、終了コードに影響しない。lint を実行できなかったときは `[SKIP]` と表示し、検査済みとはみなさない。
4. **修正は 2 回まで**。警告をゼロにすることを目的にしない。専門用語、固有名詞、意図した短い見出し語は残す。

## 修正指示への使い方

ユーザーから「主文がない」「何をするのか曖昧」「誰が何をしたか分からない」「対句で印象だけ強い」と言われたときは、文体を全体に変えるのではなく、規範 1 から 4 の順に診断する。どの規範の違反かを一言で返してから、該当箇所を直す。文脈に依存していた箇所は、省いていた情報(誰が、何を、どこの)を文に書き足す。直した後に点検手順 1 と 3 を再度行う。
